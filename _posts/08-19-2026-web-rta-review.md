# CWL WEB-RTA Review

> **Certification:** WEB-RTA  
> **Platform:** CyberWarFare Labs  
> **Focus:** Web Security / Web Exploitation  
> **Difficulty:** Beginner

## Introduction

This was my first certification focused on **Web Security**, completed through **CyberWarFare Labs**. I decided to take it mainly to put into practice the knowledge I had acquired about web applications and vulnerability exploitation.

During the certification, I worked with different vulnerabilities and practical scenarios, which helped me better understand how these concepts are applied in a lab environment.

I wouldn't consider it an advanced certification, but for someone who is starting out in Web Security, I found it to be a useful experience, especially considering its affordable price.

## What I Learned

Some of the topics I practiced were:

- SQL Injection
- XSS
- SSRF
- XXE
- JWT
- IDOR
- Burp Suite
- Reconnaissance and Enumeration

What I liked the most was being able to move from studying vulnerabilities theoretically to **actually finding and exploiting them in web applications**.

## Final Thoughts

As my first certification, I had a positive experience. It helped me put what I was studying into practice and also identify some areas where I still need to improve.

It is a basic certification, but I think it can be a good starting point for someone beginning their journey into **Web Security and Web Pentesting**.
